# DrumKit

A fun and interactive drum kit web application where you can create beats using your keyboard or mouse. Built with HTML, CSS, and JavaScript.

## How to Play

1. Press the corresponding keys on your keyboard (W, A, S, D, J, K, L)
2. Or click on the drum pads with your mouse
3. Enjoy creating your own beats!

Play it here at: https://hanktchen18.github.io/DrumKit/

## What I Learned

- DOM manipulation and event handling
- Keyboard event listeners
- Sound file handling
